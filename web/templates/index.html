            Папка скриншотов…

            Откроет Deskline при входе в Windows (окно приложения, если установлено).

            Компактное окно с текущей задачей и временем записи (как в Time Doctor). Можно закрыть — снова включите здесь или из трея.

            RDP vision (Pro)

            Опционально: ИИ по скрину окна Remote Desktop угадывает приложение внутри сессии. Кадры уходят в ваш API (не наш). По умолчанию выкл. Неуверенные ответы оставляют «RDP · host». Focus % считается по локальным сессиям.

            Оплата через Lemon Squeezy. После покупки вставьте ключ сюда. Trial Pro — 14 дней с первого запуска.

            Данные

            Экспорт — Pro. Очистка данных — внизу страницы настроек.

            Компания (LAN hub)

            Режим компании входит в тариф Team. На Free/Pro кнопка ниже заблокирована — активируйте ключ Team в блоке лицензии.

            1. Хаб: активируйте Team → включите «Режим компании» → слушайте 0.0.0.0 → добавьте сотрудника и скопируйте токен.
            2. Агент: на другом ПК впишите URL hub (http://<IP-хаба>:8787) и ingest-токен ниже → сохраните.
            3. Закрытые сессии агента появятся в сводке команды на хабе. Облако активности не требуется.

            После смены адреса прослушивания перезапустите Deskline.

              Устройства

                Агент → hub (этот ПК — сотрудник)

                На ПК сотрудника укажите адрес hub и токен из карточки сотрудника. Трекинг остаётся локальным, закрытые сессии уходят на hub.
