Deskline Desktop

The browser extension tracks tabs only. Install the Windows desktop app for full app tracking, screenshots, tray controls, and the local dashboard.

  1. Run install.bat or release\DesklineSetup-*.exe from the Deskline project.
  2. Double-click the Desktop shortcut — a native window should open.
  3. Return here: the popup will show Open dashboard when Desktop is online.
