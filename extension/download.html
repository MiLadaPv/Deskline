Deskline Desktop

The browser extension tracks tabs only. Install the Windows desktop app for full app tracking, optional screenshots, tray controls, and the local dashboard. Activity stays on your PC — Time Doctor–style focus, privacy-first.

Open download hub GitHub Releases

  1. Open the download hub (Desktop running) or grab DesklineSetup-*.exe from GitHub Releases.
  2. Launch Deskline — a native window opens (dashboard on http://127.0.0.1:8787).
  3. Return here: the popup shows Open dashboard when Desktop is online.
